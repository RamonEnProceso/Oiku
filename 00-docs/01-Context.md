# Context

## Overview
Oiku it's an AI-powered Expense Tracker.

## Problem
I use Google Sheets to manage my money, but I know that in the future, it will become a large spreadsheet file with poor organization and management. 

Also, because it is mainly a visual tool, it would be difficult to create algorithms to monitor my financial movements and get financial recommendations directly from Google Sheets.

To solve this, I decided to build a backend that reads my Google Sheets data and stores it in a PostgreSQL database, which I will analyze using Python.

That idea eventually became the idea of entering my financial information through a better-designed interface instead of just scrolling down and entering a number.

Oiku became an AI-powered expense tracker that helps me optimize my budget and save money.
